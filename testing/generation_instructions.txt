Run the following commands in your console from the main Inouma folder to generate test users, 
requirements, unavailabilities, machines, trainings, and certifications:

First cd to the main Inouma folder that holds the manage.py file.

FOR DEMO (2 users only):
0. python manage.py shell < testing/generate_demo_location.py
1. python manage.py shell < testing/generate_test_machines.py
2. python manage.py shell < testing/generate_demo_users.py
3. python manage.py shell < testing/generate_test_requirements.py
4. python manage.py shell < testing/generate_test_unavailabilities.py
5. python manage.py shell < testing/generate_trainings.py
6. python manage.py shell < testing/generate_test_certifications.py
7. python manage.py shell < testing/generate_demo_training_sessions.py
8. python manage.py shell < testing/link_machines_to_trainings.py

FOR FULL TEST SETUP (50 users):
0. python manage.py shell < testing/generate_demo_location.py
1. python manage.py shell < testing/generate_test_machines.py
2. python manage.py shell < testing/generate_test_users.py
3. python manage.py shell < testing/generate_test_requirements.py
4. python manage.py shell < testing/generate_test_unavailabilities.py
5. python manage.py shell < testing/generate_trainings.py
